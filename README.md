# Outline VPN Telegram Bot

Телеграм-бот для продажи и управления подписками Outline VPN через Telegram Stars. Развертывание через Docker Compose.

## Быстрый старт

```bash
# Клонируйте репозиторий (замените URL на актуальный)
git clone https://github.com/your-repo/outline-vpn-bot.git
cd outline-vpn-bot

# Настройка окружения
cp .env.example .env
# отредактируйте .env файл (см. раздел ниже)

# Запуск
docker-compose up -d
```

## Переменные окружения (.env)

```env
# Обязательные параметры
TG_API_KEY=токен_бота_от_BotFather
OUTLINE_API_URL=URL_API_вашего_Outline_сервера
ADMIN_IDS=id_админов_через_запятую (например: "731539795,123456789")

# Опциональные (для тестов)
PROVIDER_TOKEN=test  # или реальный токен для платежей
```

**Примечание:** Цены подписки хранятся в файле `data/prices.json` и управляются через админ-панель (изначальные значения: 1 мес - 80 ⭐, 3 мес - 210 ⭐, 6 мес - 390 ⭐, 12 мес - 720 ⭐).

## Админ-функции

Администраторы (ID указаны в ADMIN_IDS) имеют доступ к специальной панели через команду `/admin` или кнопку "👑 Админ-панель":

- 📊 **Общая статистика** — количество пользователей и активных подписок
- 👥 **Список пользователей** — детальная информация с навигацией по страницам
- 💰 **Изменение стоимости** — изменение цен подписки в реальном времени
- 📥 **Скачать БД** — резервная копия базы данных
- **Закрыть** — закрыть админ-панель

### Как изменить цены:
1. В админ-панели нажмите "💰 Изменить стоимость"
2. Введите 4 числа через пробел (цены за 1, 3, 6 и 12 месяцев)
3. Пример: `80 210 390 720`
4. При ошибке можно ввести заново или "отмена" для отмены

## Основные команды Docker

```bash
# Запуск
docker-compose up -d

# Остановка
docker-compose down

# Просмотр логов
docker-compose logs -f

# Перезапуск бота
docker-compose restart bot
```

## Примечания

- Все данные сохраняются в папке `./data` (база данных и настройки цен)
- Убедитесь, что папка `data` существует и доступна для записи
- При проблемах проверьте корректность `.env` файла и смотрите логи
- Для тестирования платежей используйте `PROVIDER_TOKEN=test`
- Админ-панель доступна только пользователям с ID, указанными в `ADMIN_IDS`
